Android 安装

  1. 允许「安装未知来源应用」，直接安装 APK 即可，官方签名无需额外处理。
  2. 如果手机上装的是本仓库此前构建的 debug 签名 2.1.0，签名不同无法覆盖安装，需先卸载旧版；卸载前建议先备份聊天身份数据。

iOS 安装

  1. IPA 无签名，不能直接安装。用 Sideloadly 或 AltStore 配合自己的 Apple ID 重签。
  2. 免费 Apple ID 签名 7 天过期，续签时不要先卸载 App，以免丢数据。
  3. 分享扩展依赖 App Group group.chat.bitchat，免费账号可能无法配置；详细步骤见 SIGNING.md。

校验下载

  • PowerShell：Get-FileHash .\文件名 -Algorithm SHA256
  • 与页面上的 SHA-256 或 .sha256 文件内容比对，一致即为完整文件。
